# layout-architecture-boards

A personal Codex Skill for planning, composing, reviewing, and preflighting
evidence-led architectural presentation boards, drawing sheets, portfolios,
and long-format review boards.

The repository root is the Skill package. `SKILL.md` is the entry point;
`references/`, `assets/`, `scripts/`, and `agents/` contain the supporting
guidance, reusable brief, PDF audit script, and metadata.

This package distinguishes project evidence, generic references, author
analysis, design proposals, and unresolved items. It does not authorize
formal drawing or submission output by itself; project-specific instructions,
human review, and printer requirements remain authoritative.
