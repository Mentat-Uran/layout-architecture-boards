# 建筑图板视觉与输出 QA

## 1. 阶段定义

| 阶段 | 允许通过的证据 | 不得声称 |
| --- | --- | --- |
| 内容清单 | 路径、来源、尺寸、角色和未知项已核对 | 已完成排版 |
| 方案级预排版 | 网格、图框、阅读顺序、无文字检查和初步渲染 | 正式尺寸已批准、最终可提交 |
| 可编辑正式排版 | 用户批准的内容与尺寸已进入可编辑源文件，链接和文字状态可检查 | 印刷 PDF 已通过 |
| 印刷/提交输出 | 视觉检查、预检、PDF 技术检查和打印方要求均通过 | 用户/教师已审核，除非确有确认记录 |

## 2. 视觉检查矩阵

| 视图 | 主要问题 | 通过条件 |
| --- | --- | --- |
| 整页缩略图 | 层级、节奏、分区、意外空洞 | 能先看到板名/案例/主图；模块顺序明确；没有单个角落过重 |
| 远距模拟 | 标题与主判断 | 不靠正文即可知道主题与案例边界 |
| 中距 | 图组、步骤、A/B | 图组归属明确；箭头和顺序可追；现状/方案差异明显 |
| 100%/实尺寸 | 正文、图注、线宽、比例尺 | 不挤、不糊、不重叠；最小必要文字可读 |
| 200% 局部 | 像素、接缝、伪字符、裁切 | 没有拉伸、黑块、锯齿、生成伪字或关键证据损失 |
| 无文字 | 图像论证 | 能识别对象、关系、步骤和主要比较 |
| 灰度/低饱和 | 对比与线宽 | 不只靠色相区分关键状态；细线仍可见 |

## 3. 内容与证据检查

- 每张图都能指出来源或明确标注为作者图解/方案。
- 项目事实、通用参考、作者分析、设计延伸和未知项没有混写。
- AI 图没有承担地形、尺寸、节点、排水终点或工程性能证明。
- 相似照片按证据功能去重，不因版面空白重复堆图。
- 主图与辅助图的角色从尺度、位置和图注上均能识别。
- 每个模块只有一个主要判断；正文不重复描述图面已经清楚表达的内容。
- 图注紧邻所属图，来源和状态在最终尺寸可读。

## 4. 几何与图像检查

- 页面尺寸、方向、页数和页面范围与任务一致。
- 外边距、沟槽、模块间距和页脚安全区一致。
- 图框共享基线，文本栏跟随真实图组边界。
- 相关平面/剖面/立面已协调；需要同尺度时严格同尺度。
- A/B 具有相同视角、方向、图框和裁切逻辑。
- 所有图片保持宽高比；摄影主体未被切断；技术图未因 cover 丢失完整关系。
- 公开 PDF 裁片、CAD、扫描图和照片的有效分辨率满足最终输出。
- 比例尺、北箭头、图名、编号和引线按任务需要存在且一致。

## 5. 文字检查

- 字体家族和语义角色数量受控。
- 板名、章节、模块、正文、图注、身份/页脚形成稳定层级。
- 同级标题使用相同字号、字重、颜色和位置。
- 正文未因空间不足被单独缩小；长句已压缩或重排。
- 所有文字无溢出、截断、孤行、错别字、伪字符和错误换行。
- 中文字体已嵌入或按打印方流程正确打包；字体许可证允许预期输出。

## 6. InDesign 预检

1. 打开 `Window > Links`，检查 Missing、Modified、色彩空间和 Effective PPI。
2. 打开 `Window > Output > Preflight`，使用项目/打印方配置。
3. 检查缺失字体、溢出文字、低分辨率、非打印对象、隐藏层和页面外对象。
4. 确认页面范围、出血、Slug、裁切标记和打印方要求。
5. 确认色彩转换与 Destination profile；没有打印方要求时不要擅自承诺 CMYK/PDF/X 方案。
6. 需要交接时使用 Package，保留 INDD、IDML、链接、允许打包的字体、报告和 PDF。

## 7. PDF 技术检查

优先运行 Skill 自带脚本；必要时单独执行：

```bash
pdfinfo board.pdf
qpdf --check board.pdf
pdffonts board.pdf
pdftotext -layout board.pdf -
pdfimages -list board.pdf
pdftoppm -png -r 18 board.pdf qa/board
```

解释边界：

- `pdfinfo` 证明页数和物理尺寸，不证明视觉正确。
- `qpdf --check` 证明 PDF 结构可解析，不证明图文没有重叠。
- `pdffonts` 证明字体记录与嵌入状态，不证明字号可读。
- `pdftotext` 可检查关键文字和占位词，但不能证明排版位置。
- `pdfimages -list` 可发现嵌图数量/类型异常，但不能证明选图正确。
- Skill 审计脚本会报告 `pdfimages` 给出的有效 PPI 范围；只有打印方或任务已给出阈值时才传入 `--min-image-ppi`，不要自行把常见数值变成硬标准。
- PNG 渲染证明当前渲染器能显示页面；必须再做整页和局部人工检查。

## 8. 输出前必须向打印方确认

- 成品尺寸、是否按比例缩放、最大页面限制；
- 出血与标记；
- PDF 版本或 PDF/X；
- 色彩空间与 ICC 配置；
- 位图有效分辨率；
- 黑色、透明、叠印和专色要求；
- 是否需要字体转曲、嵌入或打包源文件；
- 单页/拼版、裁切、装裱与传输文件大小限制。

未获得这些信息时，可以制作技术上健康的审阅 PDF，但不得声称“已满足印厂要求”。

## 9. 交付记录

至少记录：

- 源文件和输出 PDF 的绝对路径；
- 页面数量和毫米尺寸；
- 采用的版本、回退版本和未覆盖的原文件；
- 视觉检查视图；
- 预检工具、结果和警告；
- 人工未决项、证据未知项和打印方未决项。
