# 长竖向建筑图板项目配置：第五次汇报经验

本文件记录 `/data/projects/工地实习` 第五次汇报 v6–v12 的可复用经验。只在当前项目，或内容结构高度相似的“方法带 + 两个案例 + 证据/分析/方案对照”长板中使用。不要把具体尺寸、模块名或照片比例当成普遍建筑排版标准。

## 1. 当前项目的内容逻辑

- 保留顶部生产流程为一条方法带。
- 把 Geislingen 组织为 G1 技术剖面/第五立面、G2 四步附加层关系、G3 彩色光伏作者延伸。
- 把体育中心组织为 S1 证据优先的共用现状基线、S2 同尺度檐口/水路径 A/B、S3 同尺度分缝/大板块 A/B。
- 按 `资料支持 / 分析 / 现有问题 / 生成过程` 组织说明；让说明块边界跟随实际图组，不跨越无关图像。
- 把效果/氛围图与技术/证据图分开。生成图只承担作者表达，不承担项目事实。

## 2. v6–v12 暴露的问题与修正

| 版本/问题 | 失败表现 | 可复用修正 |
| --- | --- | --- |
| v6 旧长板 | 600 × 1640 mm 内同时容纳完整图量、照片和文字，局部密度与字号受压 | 先判断信息量是否适合既定板高；不要把旧尺寸当成不可讨论的常量 |
| v7 横向并排过多 | 同一行塞入太多图，技术关系和照片都变小 | 减少同排数量，按证据功能去重，必要时改为上下两行 |
| v8 竖向阅读修订 | 顺序改善，但宽图/照片仍可能被挤成窄带 | 在选图前锁定比例安全图框；把“读得清”置于“所有内容都放进一行”之前 |
| v9 比例安全修订 | 需要同时容纳摄影主体、技术图和长板阅读 | 当前项目把摄影框维持在约 16:9 或更舒展；G1/G2 使用四列证据带，G3 三图等高，S1 共用证据轨道，S2/S3 左侧照片上下两行、右侧 A/B 同尺度；用 600 × 1800 mm 方案级候选消化高度 |
| v10 图文边界 | 字虽能放下，但说明可能跨错图组或挤成过长单行 | 让文字栏按真实图组分界；G1/G2 在两张图组边界处分栏，G3 跟随三列，S1 跟随证据轨道与模型，S2/S3 说明归入共享 A/B 范围 |
| v10–v12 字号 | 只放大局部标题会破坏层级；正文仍不醒目 | 保持图片比例和骨架不变，对板名、分区、模块标题、正文、图注、身份和页脚做全局同比候选；先比较 1.15/1.30/1.45，再比较 1.65/1.80；本项目最终选择 1.80，但该数值不是通用标准 |

## 3. 当前已验证的布局动作

- 先固定照片/图解框比例，再选可追溯素材并做主体安全裁切。
- 技术图和关系模型使用完整显示；只裁源图无效空边，不切断构件关系。
- G1 让技术剖面成为主图，真实照片和 Plan 成为相邻证据，而不是用效果图替代剖面。
- G2 保留四步连续关系与对应证据带，使序列一眼可追踪。
- G3 把最后版本 B 作为主安装关系，A 作为辅助分解，通用 PV 样板降为参考说明。
- S1 让现场/公开证据和最后版关系模型共享上下基线。
- S2/S3 保持 A/B 同尺度、同视角、同基线；证据照片不再压成细长条。
- 通过增加有效板高、扩大关键图片、控制间隙消化内容；不靠无依据新图片填空。
- 保留 v6–v11 作为对照和回退，不覆盖旧 PDF 或用户选定的 S1–S3 资产。

## 4. 必须持续保留的边界

- 当前 600 × 1800 mm v12 是方案级候选，不等于教师确认的正式提交尺寸。
- 照片约 16:9 是当前素材与长板结构形成的项目配置，不是所有建筑摄影的最低比例。
- 现状照片、公开剖面和通用节点按功能去重；不能因空间允许就重复堆叠。
- 同尺度 A/B 不允许为“看起来更满”分别缩放。
- S2 的排水终点、S3 的真实板块模数、G3 的光伏工程条件仍需证据或设计者确认。
- AI 不能决定主次层级、视点、隐藏构造、尺寸或未知工程条件；用户保持最终决策权。
- `生成过程` 只适用于当前方案审阅。若以后获准进入正式图板，删除过程评论和 AI 工作流说明，只保留简洁标题、判断、来源、`待核验` 或 `设计假设`。
- 让标题与图像实际证明的内容一致。若 S2 尚未画出水的起点、路径和终点，就使用“连续边缘控制方向 / 排水终点待确认”等准确标题，不得写成“终点更清楚”。
- 正式版把“实证 / 资料”等泛化标签落实为可追溯的机构、图纸、原照片号或通用厂家资料身份。
